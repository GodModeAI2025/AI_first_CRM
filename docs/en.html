How it is stored.

Each record has its own file. Its UUID remains stable even when its display name changes.

status: "TODO"

The excerpt shows the task's metadata block. File names in the folder illustration are shortened; full UUIDs are stored.

How the project works today

Clear capabilities.
Clear boundaries.

  • Conversation for interaction, HTML for read-only views.
  • Workflows run on the next invocation; there is no background service.
  • Messages and events come from imported files. Outgoing messages remain drafts.
  • Access control belongs in your file storage. Git team mode uses authenticated GitHub access and protected checks. How the agent processes data depends on your chosen provider.
