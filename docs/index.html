Firmen, Kontakte, Deals und Aufgaben liegen als Markdown-Dateien in deinem Arbeitsraum. Stabile Kennungen verbinden sie miteinander. Wähle eine Ansicht, um Ablage, Beziehungen und Darstellung desselben Beispiels zu sehen.

So liegt es im Ordner.

Jeder Datensatz hat eine eigene Datei. Die UUID bleibt stabil, auch wenn sich sein angezeigter Name ändert.

Dein Arbeitsraum/ └── records/ ├── company/ │ └── 61e37838….md ├── task/ │ └── 0d5b33f5….md └── workspace-member/ └── 57f057d5….md
title: "Angebot nachfassen"
status: "TODO"
assignee: "[[records/workspace-member/57f057d5-431e-490a-9aee-984a166d9b62|Anna Admin]]"
targets:
  - "[[records/company/61e37838-3154-4acc-b2c9-62d6ea20ab04|Acme Holding GmbH]]"

Der Dateiausschnitt zeigt den Metadatenblock der Aufgabe. Die Dateinamen im Ordnerbild sind gekürzt; gespeichert werden vollständige UUIDs.

So hängen die Dateien zusammen.

Die Aufgabe speichert zwei Verweise: auf die Firma und auf das zuständige Teammitglied.

Auch von der Firma aus auffindbar. Die Gegenrichtung wird aus den Verknüpfungen berechnet. Dafür wird die Aufgabe nicht ein zweites Mal bei der Firma gespeichert.

Durchgezogene Pfeile stehen für gespeicherte Verweise. Der gestrichelte Hinweis beschreibt die berechnete Gegenrichtung.

So wird daraus eine lesbare Ansicht.

Der erste Arbeitsraum

Klein anfangen.
Mit dir wachsen.

01

Installiere den Skill in einem Agenten mit lokalem Dateizugriff. Die Laufzeit braucht Python 3.9 oder neuer.

02

Wähle einen Ordner und beschreibe Zweck, Sprache und Team. Dein Agent führt dich durch die Einrichtung.

03

Übernimm Kontakte, baue deine Pipeline auf und öffne die erzeugten Ansichten im Browser.

So arbeitet das Projekt heute

Klare Möglichkeiten.
Klare Grenzen.

  • Gespräch als Bedienung, HTML als schreibgeschützte Ansicht.
  • Workflows laufen beim nächsten Aufruf; es gibt keinen Hintergrunddienst.
  • Mails und Termine kommen aus importierten Dateien. Ausgehende Nachrichten bleiben Entwürfe.
  • Zugriffsschutz gehört in deine Dateiablage. Die Datenverarbeitung des Agenten hängt vom gewählten Anbieter ab.
